Two-way ANOVA

Memory Performance: Spacing × Material

Spacing, material and their interaction were not significant: spacing F(2,174)=0.646, p=.525; material F(1,174)=0.144, p=.705; interaction F(2,174)=0.646, p=.525.

Partial eta-squared values were below .01, so the visible line changes represented negligible practical differences rather than a reliable experimental effect.

Paired-samples t-test

Stress Intervention Evaluation

Mean stress decreased from 7.4 to 4.2, a 3.2-point reduction. The paired result was significant, t(4)=4.00, p=.020, 95% CI [0.81, 5.59].

Every participant moved downward in the visual, but the sample contained only five people, so the effect should be treated as promising rather than broadly generalisable.

Chi-square methods

Categorical Preference Analysis

A goodness-of-fit test found 54 versus 46 preferences did not differ from a 50/50 expectation, χ²(1)=0.64, p=.424. A separate independence test found a gender–preference association, χ²(1)=4.74, p=.030.

Adjusted residuals of approximately ±2.38 identified which cells drove the overall association, moving the interpretation beyond a single p-value.
